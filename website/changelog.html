Changelog

Version history and release notes for Open CLI.

v2.0.0
2026-06-02

Major Expansion

  • 45 built-in skills (added Solidity, Swift, Kotlin, C++, R, Terraform, Elixir, WASM, Three.js, CI/CD, WordPress)
  • 26 MCP servers (added Google Drive, FTP, S3, Dropbox, Notion, Linear, Stripe, Supabase)
  • 17 AI providers (added OpenRouter with free model tier)
  • AI Ensemble Mode — query all AIs simultaneously, synthesize best answer
  • Multi-window IPC — share context between terminal windows
  • SQLite context compression — reduce token usage automatically
  • Cross-device sync command (account required)
