Browser "Eyes"

Playwright-powered
visual verification

Ask Open CLI to verify your UI. It will navigate to the page, check buttons exist and are clickable, verify forms work, scroll the page, and take a full-page screenshot.

  • ✓ Screenshot full pages or elements
  • ✓ Verify buttons, links, forms are clickable
  • ✓ Check for console errors and 404s
  • ✓ Extract data from rendered pages
  • ✓ Scroll and interact with dynamic content
Requires Playwright — desktop only

Safety Sandbox

3-tier risk scoring
on every command

Every tool call is assessed for risk before execution. Safe reads run automatically. Destructive operations require explicit confirmation.

✓ LOW Read-only: ls, cat, grep, git log, npm list auto
⚠ MED Elevated: sudo, npm install -g, git push --force [Y/n]
✕ HIGH Destructive: rm -rf, DROP TABLE, dd, mkfs type "yes"
# Preview without running
$ opencli --dry-run "delete log files"
[DRY RUN] find . -name "*.log" -delete
🔍

Diff Preview

Before writing any existing file, a diff preview shows exactly what will change.

🔐

Sensitive Path Detection

Reading ~/.ssh/*, .env, or *.pem automatically upgrades to MEDIUM risk.

⚡

Auto-approve Low Risk

Use -y flag to auto-approve all LOW risk commands in trusted environments.
